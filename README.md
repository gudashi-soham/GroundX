# GroundX - Smart Sports Ground Booking System

GroundX is a web-based Smart Sports Ground Booking System designed to make
sports ground booking easier, faster, and more organized.

The system allows users to view available sports grounds, check available
time slots, and make bookings. Ground owners can manage their grounds and
view booking analytics.

---

## 🚀 Features

### 👤 User
- User registration and login
- View available sports grounds
- Check available date and time slots
- Book sports grounds
- View booking status

### 🏟️ Ground Management
- Add and manage sports grounds
- Store ground location and pricing
- Manage available time slots
- Track booking status

### 📊 Owner Analytics
Ground owners can view useful booking information through analytics.

Analytics are implemented using:

- **Pandas** – Data processing and analysis
- **Matplotlib** – Data visualization

The analytics can help owners understand:
- Total bookings
- Booking trends
- Popular time slots
- Ground usage
- Underused time slots
